# 无障碍拼音安装源

本仓库仅存放 SideStore / AltStore 的安装包与源描述文件，**不包含任何源码**。

源码仓库为私有，不对外公开。

## SideStore 源地址

```
https://github.com/likehao0522cn-gif/AccessibleIME-store/releases/latest/download/source.json
```

## 使用方法

1. 打开 SideStore
2. 进入 Sources（源）页面
3. 点右上角 + 号
4. 粘贴上面的地址
5. 添加后即可安装「无障碍拼音（测试）」
6. 以后有新版本时，在 SideStore 更新页刷新即可
